# Truth Guard

Truth Guard is a project focused on helping users evaluate information and identify potentially misleading or unreliable claims.

## Features

- Analyze claims and supporting information
- Highlight possible misinformation
- Present results in a clear, easy-to-understand format

## Getting Started

Clone the repository and follow the setup instructions provided by the project files:

```bash
git clone <repository-url>
cd Truth_Guard
```

Install the required dependencies using the package manager configured for the project, then run the application according to its entry point.

## Usage

Provide a claim, article, or other piece of information to the application for analysis. Review the returned assessment and supporting details critically.
